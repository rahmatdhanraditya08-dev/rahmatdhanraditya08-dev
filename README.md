### 💫 About Me
Saya adalah mahasiswa **Teknologi Rekayasa Konstruksi Instrumen dan Kontrol** yang berfokus pada sinkronisasi antara desain hardware yang presisi dan logika software yang efisien. Saya memiliki pengalaman dalam membangun sistem otomasi industri, robotika, dan IoT dari tahap skematik hingga implementasi lapangan.

- 🔭 **Proyek Berjalan:** IoT Smart Farming untuk monitoring udang Vaname & Robot Transporter ESP32.
- ⚡ **Keahlian Utama:** Embedded Systems, PLC Programming, & PCB Layouting.
- 🌱 **Sedang Mendalami:** Signal Processing & Advanced Control Systems.
- 💬 **Tanya saya tentang:** Arduino, ESP32, Modbus RTU, PLC Mitsubishi, atau CAD Design.

### 🚀 Highlight Projects
*   **📡 IoT Smart Farming:** Sistem monitoring kualitas air (pH, Temp, Turbidity, DO) tambak udang Vaname.
*   **🤖 Robot Transporter:** Robot pengangkut barang dengan kendali ESP32 dan mekanisme lifting motorik.
*   **🖐️ Gesture Recognition:** Program asisten bahasa isyarat real-time menggunakan OpenCV dan MediaPipe.
*   **💓 Heartbeat Sensor:** Perancangan sirkuit analog heartbeat menggunakan TCRT5000 dan Op-Amp LM358.
