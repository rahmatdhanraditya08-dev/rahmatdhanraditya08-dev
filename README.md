### 💫 About Me
Saya adalah mahasiswa **Teknologi Rekayasa Konstruksi Instrumen dan Kontrol** yang berfokus pada integrasi sistem antara perangkat keras (*hardware*) dan perangkat lunak (*software*). Saya memiliki minat besar dalam membangun solusi cerdas melalui IoT, robotika, dan otomasi industri.

- 🔭 **Proyek Berjalan:** Pengembangan Smart Farming Tambak Udang & Robot Transporter.
- ⚡ **Keahlian Utama:** Embedded Systems, PLC Programming, & Computer Vision.
- 🌱 **Sedang Mendalami:** Signal Processing & Deep Learning untuk optimasi industri.
- 💬 **Tanya saya tentang:** Arduino, ESP32, Modbus RTU, PLC Mitsubishi, atau MATLAB.

### 🚀 Highlight Projects
*   **📡 IoT Smart Farming:** Sistem monitoring parameter air (pH, Temp, Turbidity, DO) untuk tambak udang Vaname berbasis webserver real-time.
*   **🤖 Robot Transporter:** Robot pengangkut barang dengan 4 motor DC dan sistem pengangkat, dikendalikan via ESP32.
*   **🖐️ Gesture-to-Speech:** Program asisten bahasa isyarat menggunakan Python, OpenCV, dan MediaPipe untuk pelacakan tangan secara *real-time*.
*   **💓 Heartbeat Sensor Circuit:** Perancangan sirkuit analog sensor detak jantung menggunakan TCRT5000 dan Op-Amp LM358.
*   **⚡ Variable Power Supply:** Desain catu daya non-simetris berbasis LM317 dengan sistem proteksi terintegrasi.
