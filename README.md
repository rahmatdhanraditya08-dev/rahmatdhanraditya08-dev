### 🚀 Featured Engineering Projects
* **📡 IoT Smart Farming:** A real-time monitoring system for Vaname shrimp ponds, tracking critical parameters including **pH, Temperature, Turbidity, and Dissolved Oxygen (DO)** via a web server.
* **🤖 Robot Transporter:** A robust material-handling robot utilizing a **4-motor DC drive** and a motorized lifting mechanism, integrated with **ESP32** wireless control.
* **🖐️ Gesture Recognition:** An AI-driven sign language assistant developed with **Python, OpenCV, and MediaPipe** for real-time hand-tracking and gesture-to-speech conversion.
* **💓 Heartbeat Sensor Circuit:** Custom analog signal conditioning circuit utilizing **TCRT5000** infrared sensors and **LM358** operational amplifiers for precise pulse detection.
* **⚡ Variable Power Supply:** A regulated non-symmetrical power supply based on the **LM317** IC, featuring integrated overcurrent protection and adjustable output.
